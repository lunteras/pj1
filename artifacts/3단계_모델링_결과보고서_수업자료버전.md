# 3단계 모델링 결과 보고서 — 수업자료 버전

> **이 문서는 기존 보고서와 다른 버전입니다.** 같은 실험·같은 확정 수치를 담지만, 기존 보고서(결과 중심 심사용)와 달리 **수업자료 수준의 설명용**으로 쓰였습니다. 처음 보는 사람이 수업에서 배운 순서대로 따라올 수 있게 문제 → 데이터 → 모델 → 평가 → 한계 순서로 재구성했고, 어려운 용어는 처음 나올 때 괄호로 풀었습니다.
> (작성 비고: 수업자료 원문 PDF를 이번 세션에서 읽지 못해 문체는 수업에서 정리한 규칙 문서의 규범에 맞췄습니다. 원문 대조 후 문체 미세 조정이 가능합니다.)

## 1. 문제 정의와 평가 지표를 고른 근거

### 1-1. 무엇을 맞히려 했나

보험 회사의 입장에서 이런 고민이 출발점입니다.

> "보장성 보험만 가입한 고객에게 전부 추가 가입을 권유하기엔 상담 인력이 부족하다. 누구부터 전화할까?"

이 질문을 데이터 문제로 바꾸면 이렇게 됩니다.

```text
2024년 말까지 보험을 보유한 고객 38,932명이 있다.
2025년에 실제로 새 상품을 가입한 고객은 1,137명(2.9%)이다.
2024년 말까지 알 수 있던 정보만으로, 누가 2025년에 가입할지 맞혀 보자.
```

핵심은 **"2024년 말까지 알 수 있던 정보만"**이라는 조건입니다. 미래를 이미 아는 척하면 정답을 베끼는 것이므로, 예측에 쓰는 13개 특성은 전부 예측 시점 이전 값입니다.

### 1-2. 데이터 한 장 요약

| 항목 | 내용 |
|---|---|
| 원본 | 보험·증권 혼합 385,019행 중 **보험만** 사용(증권 고객과 겹침 0명) |
| 고객 | 74,776명 중 2024년 말까지 보유한 **기존 고객 38,932명** |
| 정답 | 2025년 신규 가입 여부 — 가입 1,137명(**2.9%**) |
| 불균형 | 가입 : 미가입 = **1 : 33.2** |
| 특성 | 13개(연령·성별·지역·소득·직업·위험등급·신용·결혼 8범주 + 경과연수·납입액·상품금액·보유수2+·특약보유 5개) |

### 1-3. 평가 지표를 고른 근거 — 왜 "정확도"를 버렸나

불균형 데이터에서 정확도는 함정입니다. 예를 들어 보겠습니다.

> 전 고객에게 "가입 안 할 거예요"라고만 찍어도 정확도는 **97.1%**입니다. 모델이 아니라 누구나 만들 수 있는 답인데도 점수가 거의 만점입니다.

그래서 이 프로젝트는 **리프트(끌어올림 효과)**로 평가했습니다. 모델이 가장 가능성 높다고 고른 **상위 1,000명**을 상담했을 때, 그 안에 실제 가입자가 몇 명 들어 있는지 보는 방식입니다.

| 비교 | 상위 1,000명 중 실제 가입 |
|---|---:|
| 무작위로 1,000명 | 약 29명 (2.9%) |
| 모델 상위 1,000명 | **약 82명 (8.2%)** |

**판정 기준은 모델링 시작 전에 합의**했습니다 — "상위 1,000명 가입률이 5.8%(기준선의 2배)를 넘으면 도입 가치 있음". 나중에 기준을 맞춰 바꾸면 시험 부정이 되므로, 먼저 고정했습니다. 또 한 번의 분할이 아니라 **시드 42~61로 20번 반복**해 평균±표준편차로 보고해 우연을 제거했습니다.

### 1-4. 로지스틱 회귀가 이 문제에 맞는 이유

로지스틱 회귀(각 특성에 중요도를 곱해 더한 값을 0~100% 확률로 바꾸는 모델)는 이 프로젝트에서 두 가지 이유로 기본기 역할을 합니다.

1. **상담 현장에 설명이 필요합니다** — "이 고객은 특약을 보유하고 있고(기여 +0.84), 상품을 두 개 보유하고 있어서(가입률 4.1배) 상위권입니다"처럼 이유를 말할 수 있어야 상담사가 믿고 씁니다.
2. **신호가 전부 약한 데이터입니다** — 개별 특성의 상관이 최대 +0.070(보유 상품 수)이라, 화려한 모델보다 약한 신호들의 조합을 투명하게 보여주는 모델이 맞습니다.

## 2. 모델별 성능 비교

### 2-1. 공정한 비교 규칙

시험 문제가 같아야 실력 비교가 됩니다. 네 모델은 전부 **같은 데이터·같은 70/30 분할(20시드)·같은 특성·같은 지표**를 사용했습니다. 불균형 보정(양성 1건을 약 33건만큼 무겁게 치는 class_weight)도 동일하게 적용했습니다.

### 2-2. 네 모델 소개

| 모델 | 한 줄 소개 | 성격 |
|---|---|---|
| 더미 | 전원 "미가입"이라고만 찍는 기준 답안 | 비교의 바닥 기준 |
| 로지스틱 회귀 | 특성별 중요도를 곱해 더해 확률을 만드는 기본기 모델 | 설명 가능 |
| 랜덤포레스트 | 300개의 결정 나무가 투표하는 숲 모델 | 정확도 지향 |
| LightGBM | 나무를 차곡차곡 쌓아 오차를 줄이는 부스팅 모델 | 속도·정확도 지향 |
